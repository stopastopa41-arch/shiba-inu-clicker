# Football Arena

A responsive 1v1 browser football game built with HTML5 Canvas, TypeScript and Vite.

## Features
- Player vs Bot with Easy / Normal / Hard behaviour profiles
- Local Player vs Player
- Real-time ball velocity, friction, rebounds and player collisions
- Goals, score, 2-minute match clock, rematch and main menu
- Responsive canvas presentation and touch controls
- Procedural sound effects with Sound and Music settings
- No external game engine or runtime asset dependency

## Controls
- Player 1: WASD, Shift sprint, Space kick
- Player 2: Arrow keys, Enter kick
- Mobile: on-screen directional and kick controls

## Run
```bash
npm install
npm run dev
```

Production build:
```bash
npm run build
```
